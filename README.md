# 📱 날아오르라 주작이여 1.0

이 프로젝트는 커서의 agent 모드를 90% 이상 활용하여 개발되었습니다.

나머지 10%는 CSS 다듬기, 피그마로 asset 만들기, 코드 정리 및 보완 작업을 수행했습니다.

본 애플리케이션으로 카카오톡 대화를 만들고 스크린샷으로 저장할 수 있습니다.

백엔드 서버가 따로 없어 저장 기능은 제공하고 있지 않습니다.

## ✨ 주요 기능

- **휴대폰 상태 설정**: 시간, 배터리 레벨 조정
- **대화방 정보 설정**: 제목, 참여자 수, 상대방 이름/프로필 사진, 공지사항
- **메시지 관리**:
  - 메시지 추가 (발신자, 내용, 시간, 읽음 여부)
  - 메시지 편집 및 삭제
  - 실시간 미리보기
- **스크린샷 생성**: 실제 카카오톡과 유사한 UI로 스크린샷 생성 및 저장
- **데이터 내보내기**: JSON 형태로 데이터 저장

## 🛠️ 기술 스택

- **Frontend**: Vue 3 + TypeScript
- **Build Tool**: Vite
- **State Management**: Pinia
- **스타일링**: CSS3 (Vanilla CSS)
- **스크린샷**: html2canvas

## 🚀 시작하기

### 필수 조건

- Node.js 16+
- npm

### 설치 및 실행

1. 의존성 설치:

```bash
npm install
```

2. 개발 서버 실행:

```bash
npm run dev
```

3. 빌드:

```bash
npm run build
```

4. 미리보기:

```bash
npm run preview
```

## 📁 프로젝트 구조

```
src/
├── components/          # Vue 컴포넌트
│   ├── PhoneStatusForm.vue   # 휴대폰 상태바 관련 정보 입력 폼
│   ├── ChatRoomForm.vue      # 대화방 정보 입력 폼
│   ├── MessageForm.vue       # 메시지 추가 폼
│   ├── MessageList.vue       # 메시지 목록 및 편집
│   └── KakaoPreview.vue      # 카카오톡 스크린샷 미리보기
├── stores/             # Pinia 스토어
│   └── kakaoStore.ts   # 카카오톡 데이터 상태 관리
├── types/              # TypeScript 타입 정의
│   └── index.ts        # 인터페이스 정의
├── App.vue             # 메인 앱 컴포넌트
├── main.ts             # 앱 진입점
└── style.css           # 글로벌 스타일
```

## 🎯 사용법

1. **휴대폰 상태**: 화면 상단에 표시될 시간, 배터리 등을 설정
2. **대화방 정보**: 대화방 제목, 참여자 정보, 공지사항 입력
3. **메시지 추가**: 발신자, 내용, 시간, 읽음 여부를 설정하여 메시지 추가
4. **메시지 관리**: 추가된 메시지를 수정하거나 삭제
5. **실시간 미리보기**: 오른쪽에서 실제 카카오톡 UI로 실시간 확인
6. **스크린샷 생성**: "📸 스크린샷 저장" 버튼으로 PNG 이미지 다운로드
7. **데이터 내보내기**: JSON 파일로 설정한 데이터를 저장

## 🎨 UI 특징

- **실제 카카오톡과 유사한 디자인**: 색상, 폰트, 레이아웃 재현
- **반응형 디자인**: 데스크톱과 모바일 모두 지원
- **실시간 미리보기**: 데이터 입력 시 즉시 스크린샷 업데이트
- **고품질 스크린샷**: 2배 해상도로 선명한 이미지 생성
